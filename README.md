# Land Type Classification

Deep learning project for **classifying land types from satellite imagery**.

## Features

* Satellite image classification
* Image preprocessing
* Land type prediction
* Confidence & probability visualization
* Interactive demo

## Technologies

`Python` · `TensorFlow` · `Deep Learning` · `Computer Vision`

## Demo

[**Live Demo →**](https://huggingface.co/spaces/AlshimaaAhmed/landclassification-app)

## Results

The model predicts the land type of a given satellite image and displays the predicted class with its confidence scores.
